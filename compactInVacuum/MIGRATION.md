# CompactInVacuum Schema-v3 Migration

Schema version 3 is the preferred common-platform schema for `CompactInVacuum-afterSRC` and `CompactInVacuum-preSAMURAI`.

## Mechanical mappings

| Removed schema-v2 concept | Schema-v3 replacement |
|---|---|
| `detector.cassette` | `detector.head` |
| arbitrary cassette `outer_envelope_mm[2]` | calculated detector stack depth |
| long nose and rectangular shell | shallow light-tight sleeve and rear mounting face |
| `sector_cartridge` | `sector_holder` |
| mount pad + rail + wall anchor per detector | one carrier plate with three nests |
| cylindrical thermal strap | contacting carrier/rear-face/nest/plate path |
| protruding `anti_rotation_tab_mm` | `anti_rotation_flat_depth_mm` |

The default calculated housing depth is:

`active 5.50 + coupling 0.50 + SiPM 1.50 + carrier 1.20 + clearance 0.00 + rear face 1.00 = 9.70 mm`

`CableExit`, `ConnectorKeepout`, and removal envelopes are excluded from the housing-depth metric.

## Removed monitoring fields

Schema version 3 rejects, at any nesting level:

- `temperature_sensor`
- `temperature_sensor_status`
- `temperature_channels`
- `wires_per_temperature_channel`
- `temperature_harnesses`
- `housekeeping_pin_capacity`
- `housekeeping_interface`
- `housekeeping`

These fields are not ignored, mapped to spare services, or converted into hidden geometry. Remove them from inherited and deployment YAML before loading schema version 3.

Deployment service-port roles are limited to `rotary` and `signal`. No monitoring or housekeeping port is generated by default.

## Display roles

Generated objects now carry `EngineeringRole`:

- `physical`
- `purchased_component_interface`
- `keepout`
- `datum`
- `service_centerline`
- `physics_acceptance`
- `optional_reference_geometry`

Only the first two roles are visible by default.

## Compatibility boundary

Legacy schema-1 profiles remain loadable for the old stateful entry point, with their housekeeping block removed. They do not represent the preferred detector head or sector holder.

The common and deployment sources are:

- `config/common_detector.yaml`
- `config/afterSRC_compact.yaml`
- `config/infrontSamurai_compact.yaml`

Preserved external routes are not part of this schema migration.
