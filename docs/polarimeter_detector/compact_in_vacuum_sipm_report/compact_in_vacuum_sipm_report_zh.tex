\section{执行结论}

\begin{decisionbox}{权威的两仪器项目架构}
  极化氘实验当前规划两台真空内紧凑型极化仪：
  \textbf{CompactInVacuum-afterSRC} 安装在 SRC 下游，
  \textbf{CompactInVacuum-preSAMURAI} 安装在 SAMURAI 终端之前。
  两台仪器共享 CompactInVacuum 探测器平台，但靶室几何、束线接口、靶机构集成、
  支撑和维护空间均为站点特定。此前研究的 afterSRC 外置探测器构型继续作为
  legacy/reference 备选保留，但不是当前基线。afterSRC 当前选定的是方形
  筛选靶室，不采用圆柱形方案。
\end{decisionbox}

\begin{decisionbox}{首轮原型推荐基线}
  \begin{itemize}
    \item 首轮紧凑型探测器采用快速蓝光塑料闪烁体，不采用高光产额无机晶体。
    \item 首个原型采用 canonical \SI{\ActiveDiameterMm}{\milli\meter} 直径和
      \SI{\ActiveThicknessMm}{\milli\meter} 有效厚度；量产厚度冻结前保留
      \SIrange{5}{6}{\milli\meter} 比较样片。
    \item SiPM 基准采用 NDL EQR15 11-6060D-S；NDL EQR20 作为高增益备选，
      Hamamatsu S13360-6025CS 作为进口参考器件。
    \item SiPM 有效面积上的总光收集效率按 2--5\% 设计并实测；
      该数值不是供应商固有规格。
    \item 有源电子学保持在真空外。每个快速信号使用一条屏蔽
      \SI{50}{\ohm} 同轴馈通，SiPM 偏置通过外部 bias tee 注入。
  \end{itemize}
\end{decisionbox}

对于 \SI{\ActiveThicknessMm}{\milli\meter} 候选厚度，正常 d--p 弹性散射的
最大计算沉积能为 \SI{\CandidateMaximumDepositMeV}{\mega\electronvolt}。
EQR15 在 2\% 和 5\% 光收集效率下的短脉冲微胞非线性分别为
\EqrNormalNonlinearityTwo\% 和 \EqrNormalNonlinearityFive\%。
在 5\% 情况下，计算的一次雪崩电荷为
\SI{\EqrNormalCharge}{\nano\coulomb}。因此 SiPM 本身具有足够余量，
但前端仍可能在微胞达到不可接受非线性之前削顶。首轮原型必须包含快速定时通道、
受保护的低增益电荷通道以及可标定的光注入扫描。

旧 \SI{\LegacyThicknessMm}{\milli\meter} 厚度的最大沉积能为
\SI{\LegacyMaximumDepositMeV}{\mega\electronvolt}；相同光收集效率下，
EQR15 非线性为 \EqrLegacyNormalNonlinearityFive\%，电荷为
\SI{\EqrLegacyNormalCharge}{\nano\coulomb}。

碳本底点使用未施加 Birks 淬灭的电子等效光产额，因此是保守上限。
EQR15 在该点的计算非线性为 \EqrCarbonNonlinearity\%。
重离子淬灭会降低真实占用率，但必须测量，不能直接假定。

上海谱幂公开资料表明其具备定制真空部件设计和加工能力
\cite{prmat_about,prmat_kcell}，可作为靶室集成候选方。
这些资料只构成候选证据，不等同于已经完成资格认证。采购前必须要求正式 RFQ、
可制造性评审、焊接与检验计划、尺寸报告、清洗记录和氦检漏报告。

\begin{warningbox}{afterSRC 当前检修口选择；束流与服务接口仍需证据}
  旧 afterSRC 外置探测器设计采用前后 ICF114 和顶部 ICF70，这属于 B 类
  legacy 继承。当前 CompactInVacuum 参考 CAD 也含 ICF114/ICF70 外形假设，
  但它们只是 C 类工程假设，不能作为 CompactInVacuum-afterSRC 的独立 A 类
  束线证据；CompactInVacuum-preSAMURAI 接口同样未关闭。

  canonical afterSRC 原型当前采用顶部 \MaintenanceAccessStandard\ 检修口，
  筛选净孔为 \SI{\MaintenanceAccessClearBoreMm}{\milli\meter}，使用 OFHC 铜垫片，
  禁止弹性体/O 形圈密封。脱离后载架的孔径屏蔽余量为
  \SI{\MaintenanceAccessPassageMarginMm}{\milli\meter}，但安装状态下的释放、平移、转姿和提出连续动作仍为
  \MaintenanceExtractionStatus。可拆盲板不承载探测器、支撑、定位基准、保护接地端或永久线缆固定件。
  前后束流接口、抽气、规管、全通径隔离阀、旋转和信号馈通仍需批准的站点与采购件证据。
\end{warningbox}

SRC 下游的实际纵向/横向包络、可用束流孔径、相邻设备、法兰接口、靶机构集成、
真空服务、支撑/对准以及安装维护空间。

\textbf{pre-SAMURAI 站点需求。}
SAMURAI 终端前位置的相同类别要求，必须独立建立。

未知站点量保持 TBD。关闭它们需要已批准的接口图、现场测量/测绘、相邻设备包络、
beam stay-clear、真空服务责任边界、支撑基准以及安装维护评审。

\subsection{当前集成方向}

\begin{itemize}
  \item 在获得物理证据并进行受控变更之前，保持 canonical 通道角度、
    有效中心半径和 \SI{\ActiveDiameterMm}{\milli\meter} 有效直径。
  \item 两个当前部署配置均采用有平面服务壁的方形靶室；afterSRC 使用
    $440\times440$ mm 方形筛选配置，不保留圆柱形 afterSRC 候选。
  \item afterSRC 顶部采用全金属 ICF305 盲板检修口。所有探测器支撑和定位基准
    均位于与永久腔壁接触的固定结构上，不得安装在可拆盲板上。
  \item 当前 12 mm 释放动作只是第一阶段；后续平移、转姿、提出和线缆整理必须按
    安装状态在 STEP 中独立验证。
  \item 方形选型不等于结构放行；每套靶室仍须针对实际开孔、焊缝、支撑和搬运
    工况完成外压屈曲与局部载荷计算。
  \item 束流两端使用符合各站点已批准配合标准的短、可拆采购接管；运输时保护
    密封面，并设置吊点和可人工搬运子组件质量上限。
\end{itemize}

\section{探测器物理与有效厚度}

本报告按 canonical CompactInVacuum 探测器直径、有效中心半径和实验室系角度重新计算
弹性 d--p coincidence 接受度。质心系前向重叠区约为
\ForwardCmLow--\ForwardCmHigh 度，后向重叠区约为
\BackwardCmLow--\BackwardCmHigh 度。

每一个入射动能先通过 LISE++ 表换算为射程，从射程中减去闪烁体厚度，再用
反插值求剩余能量。报告主结果使用 \LisePrimaryRangeModel，同时保留

Birks 关系作一阶描述：
\begin{equation}
  \frac{\mathrm{d}L}{\mathrm{d}x}
  =
  \frac{S\,\mathrm{d}E/\mathrm{d}x}
       {1+k_B\,\mathrm{d}E/\mathrm{d}x}.
\end{equation}
所选国产塑料批次的 $k_B$ 以及氘核、质子和碳核响应必须实测或由可靠束流数据验证。

\subsection{前端量程与通道结构}

在 \SI{\ActiveThicknessMm}{\milli\meter} 候选方案的正常 d--p 上限点和
5\% 光收集效率下，EQR15 计算电荷为
\SI{\EqrNormalCharge}{\nano\coulomb}。若分布在
\SI{20}{\nano\second} 等效时间窗内，对应平均电流约
\SI{\FrontEndAverageCurrentMilliAmp}{\milli\ampere}，
\SI{50}{\ohm} 上的电压尺度约
\SI{\FrontEndVoltageScale}{\volt}。真实峰值取决于传感器电容、线缆、
bias tee、终端和整形。

\begin{itemize}
  \item 设置快速定时鉴别通道和低增益电荷通道，或使用一个受保护宽带通道加
    两个已标定增益范围。
  \item 原型低增益积分电荷范围至少达到
    \SI{\LowGainRangeNc}{\nano\coulomb}，之后根据碳核淬灭测量修订。
  \item 使用可编程低噪声偏置，并在台架上表征工作点随温度的变化；这不构成
    真空内温度监测通道的要求。
  \item 每个生产批次测量击穿电压、增益、暗计数、串扰、后脉冲、恢复、
    空间响应、饱和与温度系数。
\end{itemize}

\subsection{SiPM 及后端读出电路的简化模型}

为解释台架和束流测试数据，应把 SiPM 理解为大量 Geiger 模式雪崩光电二极管
微胞的并联阵列，而不是响应连续可变的普通光电二极管。每个微胞包含雪崩结、
等效微胞电容 $C_{\mathrm{cell}}$ 和串联淬灭电阻 $R_q$。器件工作在击穿电压
以上：
\begin{equation}
  V_{\mathrm{bias}} = V_{\mathrm{bd}} + V_{\mathrm{ov}},
  \qquad
  Q_{\mathrm{cell}} \simeq C_{\mathrm{cell}} V_{\mathrm{ov}} .
  \label{eq:sipm-cell-charge}
\end{equation}
微胞被触发后先释放近似固定的电荷，再由淬灭电阻终止雪崩。因此在一阶近似下，
SiPM 的积分输出与同时击发的微胞数成正比。图~\ref{fig:sipm-microcell-model}
给出面向实验读出的等效模型；封装寄生参数、相关噪声和厂商特定保护结构均有意
省略。

雪崩发生后，$R_q$ 终止放电并为微胞电容重新充电，其特征恢复时间可定性写为
\begin{equation}
  \tau_{\mathrm{rec}} \sim R_q C_{\mathrm{cell}} .
  \label{eq:sipm-recovery-time}
\end{equation}
在恢复完成之前，同一微胞再次触发时释放的电荷较小，探测概率通常也降低。
因此，较宽的入射光脉冲或持续背景光会使相当一部分微胞处于未完全恢复状态；
即使事件计数率本身看似可接受，有效动态范围也会下降。

\subsection{饱和、非线性与环境光影响}

前述占用模型可用有效光电子数 $N_{\mathrm{pe}}$ 表示为
\begin{equation}
  N_{\mathrm{fired}}
    = N_{\mathrm{cell}}\left[
      1-\exp\left(-\frac{N_{\mathrm{pe}}}{N_{\mathrm{cell}}}\right)
      \right].
  \label{eq:sipm-occupancy-npe}
\end{equation}
当 $N_{\mathrm{pe}}\ll N_{\mathrm{cell}}$ 时，
$N_{\mathrm{fired}}\simeq N_{\mathrm{pe}}$，响应近似线性；占用率升高后，响应
逐渐偏离线性，并最终趋近 $N_{\mathrm{cell}}$。这种饱和来自可用微胞数目的
有限性，不等同于普通放大器的电压削顶。线缆色散、微胞恢复过程和后端整形仍
可能产生光滑且没有明显平顶的脉冲。因此，“波形外观看起来正常”不能证明
SiPM 仍工作在线性区。

环境光会引入持续背景计数和平均光电流 $I_{\mathrm{avg}}$，占用微胞并减少物理
信号到达时可用的完全恢复单元。若偏置网络含有串联电阻或偏置电源具有有限输出
阻抗，还会产生
\begin{equation}
  V_{\mathrm{SiPM}} = V_{\mathrm{supply}} - I_{\mathrm{avg}}R_{\mathrm{series}},
  \qquad
  V_{\mathrm{ov,eff}} = V_{\mathrm{SiPM}}-V_{\mathrm{bd}} .
  \label{eq:sipm-background-bias-drop}
\end{equation}
有效过压下降会降低增益，通常也会降低光子探测效率（PDE）。因此遮光不良会
通过“微胞占用”和“偏置跌落”两条途径压低增量脉冲幅度：继续增加入射光时，
示波器上可能只增加一小段响应，或幅度增长明显慢于预期。

图~\ref{fig:sipm-readout-chain} 也解释了为什么持续照明在示波器上可能具有
误导性。AC 耦合电容、CR 整形或其他高通环节会抑制稳定光照造成的直流分量和
慢变化分量；后端主要在光照开始或发生变化时响应。因此，阶跃式持续光照可能
只表现为一小段瞬态脉冲，随后回到基线附近，而 SiPM 仍在持续吸收背景光并产生
平均电流。遮光不良时，更强的光源可能仍只产生一小段增量响应，且没有平顶式
饱和特征。这并不排除 SiPM 已经进入非线性区，反而与微胞占用、偏置跌落和
高通读出的共同作用相符。

\begin{notebox}{实验读出要点}
  SiPM 响应同时受微胞总数、微胞恢复时间和有效过压限制；饱和不一定表现为
  明显的波形削顶。环境光既占用微胞，又通过平均电流产生偏置跌落，而 AC 耦合
  可能隐藏稳态分量，使示波器上只留下短暂响应。因此，可靠遮光和按预期平均
  电流设计的偏置网络，是获得稳定且可解释读出的必要条件。
\end{notebox}

\section{真空电气服务、接地与被动导电设计}

公共平台推荐每个探测器使用一条屏蔽 \SI{50}{\ohm} 同轴通道。
信号和偏置通过外部 bias tee 共用同轴线，有源模拟电子学保持在真空外。
十二个探测器需要十二条可独立测试的同轴馈通通道。参考 CAD 按方位分组：
四个四通道同轴包络在每个方位使用三路并保留一个可用信号位置。系统不设置
专用温度传感器、温度线束、housekeeping 通道、多针 housekeeping 馈通或强制
监测容量。信号包络采用 ICF70 只是 C 类集成假设，不是两站点的公共接口要求。
每台仪器必须在自身服务与维护包络内分别确定法兰标准、端口数量/位置、连接器
系列和准确采购料号。

北京飞迪真空公开列出 CF 接口上的 \SI{50}{\ohm} SMA50/SMAD50 馈通方案
\cite{feedivac_sma}。RFQ 必须冻结准确料号、连接器性别、真空内线缆型号和长度、
烘烤温度、氦漏证书、安装带宽和备件数量。网页数据仅用于候选筛选。

\begin{itemize}
  \item 探测器载板、扇区载架和靶室可靠连接到保护地，不能依赖不确定的可拆机械
    接触作为唯一接地。
  \item 烘烤期间闪烁体不得超过已验证工作温度；优先采用扇区可拆的受控烘烤。
  \item 真空内线缆采用低放气并机械固定的结构，避免不通气盲孔、虚漏、
    松散反射膜和无支撑连接器。
  \item 在台架上表征 SiPM 温度系数并规定偏置工作范围，但不为此建立真空内
    温度计式监测子系统。
\end{itemize}

\section{站点特定靶室、真空接口与旋转馈通}

\subsection{选定的方形靶室架构}

两个当前 CompactInVacuum 部署配置均使用方形筛选靶室：afterSRC 为
$440\times440$ mm，pre-SAMURAI 为 $450\times450$ mm。这是明确的集成选择：
永久平面壁提供固定支撑基准和服务口安装面。afterSRC 顶壁布置选定的
全金属 ICF305 检修口；CompactInVacuum-afterSRC 不保留圆柱形靶室方案。

选定架构包括：
\begin{itemize}
  \item 针对实际开孔、焊缝、支撑和搬运载荷验证的方形外压靶室；
  \item 只负责封闭真空边界的 afterSRC ICF305 可拆盲板；它不承载探测器、
    支撑、定位基准、保护接地端或永久线缆固定件；
  \item 位于固定腔壁支撑上的四套确定性扇区载架接口；已验证初始 12 mm
    释放，完整取出路径仍未关闭；
  \item 两端使用与各站点批准配合标准一致的认证采购束流件；
  \item 旋转馈通接口和采购件按站点独立确定，并分别关闭轴载荷、扭矩、回差、
    寿命、烘烤温度和维护包络。
\end{itemize}

方形选型只是集成基线，不是结构放行。最终壁厚、加强筋、盖板和开孔必须由包含
焊缝效率、局部加强、搬运载荷和初始缺陷敏感性的外压 FEA 确定。

\section{结论}

当前项目基线是两台真空内紧凑型仪器：
\begin{itemize}
  \item SRC 下游：\texttt{CompactInVacuum-afterSRC}；
  \item SAMURAI 终端前：\texttt{CompactInVacuum-preSAMURAI}。
\end{itemize}
两者共享的探测器平台包括快速塑料研究、
\SIrange{5}{6}{\milli\meter} 首轮厚度候选带、EQR15 基准 SiPM、光收集与
饱和研究、前端动态范围、十二路真空同轴架构、短探测器头、整体扇区载架、
电子学、标定和公共物理/响应研究。

两个当前 CAD 部署配置均采用方形筛选靶室。afterSRC 选用
$440\times440$ mm 方形内截面，并且不保留圆柱形靶室候选；pre-SAMURAI
采用独立受控的 $450\times450$ mm 方形配置。

靶室几何和束线接口不是公共平台常数。afterSRC compact 与 pre-SAMURAI compact
必须各自获得批准接口图、可用孔径、可用包络、靶/馈通集成、服务、支撑/对准和
维护空间定义。现有 ICF114/ICF70 数值在缺少独立 compact 站点证据时只能算
legacy 继承或工程假设。本报告不冻结新的靶室尺寸，也不放行采购件。

旧 afterSRC 外置探测器构型完整保留为 legacy/fallback/reference 路线，可用于
比较和风险控制，但不是两台当前基线仪器之一。下一架构里程碑是关闭站点
Gate 0A/0B，同时继续公共 golden detector 与 golden sector 实验。

\subsection{当前验证的局限}

d--p/d--C 能量使用仓库中的解析二体运动学和 LISE++ 射程表流程。
计算采用连续慢化近似的射程相减，不包含射程涨落、包覆/死层、
入射角路径变化、Birks 淬灭和探测器分辨。这些数值用于工程筛选，
不能替代量产前版本受控的 Geant4 模型。

SiPM 模型是一阶均匀短脉冲近似。靶室质量是封闭方壳算术估计，
不是 FEA 或实际加工质量。供应商网页只支持候选筛选；
采购以签字图纸、当前 datasheet、正式报价、批次追溯和证书为准。
