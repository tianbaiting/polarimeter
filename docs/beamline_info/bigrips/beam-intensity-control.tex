\begin{abstract}
本文记录从 SRC 出口到 BigRIPS F2/F3 之间可影响束流强度的装置、它们的物理作用，以及偏振氘束实验需要向 RIKEN 束线组确认的运行边界。结论先行：RIKEN 公开申请说明给出的 F3 总束流率上限为 $10^7$ particles/s（适用运行模式需向束线组确认）；F1、F2 和 F2--F3（dF2）狭缝可以通过减小动量、空间或角度接受度来降低传输率，而一次束模式的安全限流主要由 SRC 上游的 beam attenuator（ATT）和联锁系统管理。
\end{abstract}

\section{束线位置与功能}

BigRIPS 第一段从生产靶 F0 到 F2，第二段从 F3 到 F7；F2 与 F3 之间是约 8.8 m 的匹配段。分段来自官方配置说明，长度来自技术参数表。\cite{bigrips-config,bigrips-technical} 束流路径示意为
\[
\mathrm{SRC}\;\longrightarrow\;\mathrm{T\ course}\;\longrightarrow\;F0\;\longrightarrow\;D1/F1\;\longrightarrow\;F2\;\longrightarrow\;dF2\;\longrightarrow\;F3.
\]
F0 后的 D1 间隙内设置高功率 beam dump，用于截停未反应的一次重离子束；第一段的 F1 是动量色散焦点，F2 是消色差焦点，F3 是第二段的起点。\cite{bigrips-config} 原文见图\ref{fig:config-source}；dF2 的位置见图\ref{fig:slit-source}。

\section{F3 的强度限制}

RIKEN BigRIPS 官方束流说明要求在申请书中填写 ``Total Beam Rates @ F3''，并指出由于辐射法规，该处总束流率不能超过 $10^7$/s。官方建议在 LISE++ 中在 F3 后插入 Faraday Cup 2 检查该数值。\cite{bigrips-intensity} 原文见图\ref{fig:f3-source}。这里按总束流率计入目标核素及杂质，不能只用目标核素产额比较限值。

该说明面向 RI 束产额估算和实验申请；偏振氘一次束直通模式是否沿用同一限值，应由束线组确认。对于适用该规定的运行模式，本文据此推论：下游触发降采样只减少记录事件，不会减少经过 F3 的粒子数，因此不能替代 F3 总率控制。

\section{一次束与 RI 束模式的区别}

对于 F0 产生 RI 束的标准模式，F0、D1 beam dump、F1 degrader/slit 和 F2 collimator 共同完成一次束截停及 RI 束选择。\cite{bigrips-config,bigrips-focal} 对于将一次束送入 BigRIPS 的模式，RIKEN 2025 年 BIS 年报说明：系统根据 ATT 插入状态判断衰减是否足够；衰减不足时，会在 SRC 出口插入 Faraday cup。\cite{bis} 对应原文见图\ref{fig:bis-source}。该文另述一般报警可触发 beam chopper，不能将其直接当作 ATT 条件下的完整联锁时序。

\begin{samepage}
基于上述联锁说明，本文的工程判断是：``SRC 后保持高流强，在 F2 或 dF2 再降到允许值'' 不能仅由狭缝几何推断为可运行方案。必须确认该模式下的联锁阈值、束损位置、F2/dF2 狭缝的热负荷和屏蔽条件。
\end{samepage}

\section{对 after-SRC 偏振仪的建议}

以下为本文的实验规划建议，不是 RIKEN 已批准的运行方案。偏振氘束实验建议把需求拆成两个独立量：
\begin{enumerate}
  \item after-SRC 极化计处的一次束强度和允许的探测器计数率；
  \item F3 处（若束流继续进入 BigRIPS 下游）的总束流率，包括杂质。
\end{enumerate}
优先向束线组询问是否存在专门的局部衰减器或可接受的 F2/dF2 准直方案，而不要把普通 F2 狭缝直接当作高功率 beam attenuator。若需要保持偏振，任何材料衰减器还应单独评估多重散射、能损、核反应和可能的自旋系统误差。
