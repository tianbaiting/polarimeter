\begin{abstract}
偏极氘束沿 PIS--AVF--RRC--SRC 加速。源端的 $<100\,\mu\mathrm{A}$、AVF 后恢复测试的 $10\,\mathrm{nA}$、SRC 在 $250\,\mathrm{MeV/u}$ 下的 $30\,\mathrm{pnA}$ 预期强度，分别是源输出、具体实验用束和申请规划值，不能拼成同一次运行的传输效率。ATT 通过组合上游网格降低粒子数；AVF 到 RRC 的注入输运段已有明确安装记录。本文先统一各处强度的口径，再解释 ATT 的位置、倍率与标定，最后衔接 BigRIPS 的限流条件。各数值的来源与适用条件见下表。
\end{abstract}

\subsection{统一单位与时间口径}
设电荷态为 $q$、粒子率为 $\dot N$，电流绝对值为 $I_e$，则
\[
I_e=q e\dot N,\qquad I_p=e\dot N=I_e/q,
\qquad e=1.602176634\times10^{-19}\,\mathrm C.
\]
$\mathrm{pnA}$ 中的 p 表示 particle current；$\mathrm{enA}$ 表示电荷电流。对 $d^+$，$q=1$，二者数值相同：
\[
1\,\mathrm{pnA}=6.2415\times10^9\ \text{粒子/s},\qquad
10^7\ \text{粒子/s}=1.602\,\mathrm{ppA}=0.001602\,\mathrm{pnA}.
\]
这不是每平方厘米的 flux。面积平均通量密度为 $\bar\phi=\dot N/\mathcal A$，单位为 $\mathrm{cm^{-2}s^{-1}}$；非均匀束斑还需给出空间分布。也不能直接把散射探测器 cps 当作入射束流 pps，二者之间包含靶厚、截面、接受度和探测效率。

\section{ATT 是什么，装在哪里}
\label{sec:att}

\textbf{ATT（Beam Attenuator）用网格截去部分粒子，以改变束流强度。}2023 年 E5A 见学资料第 8 页明确说明：由加速器操作员改变上游 mesh 的组合来调束。\cite{e5a} RILAC 的硬件论文进一步给出钽网、插入杆和远程开关控制；该材料描述适用于论文中的 RILAC 装置，不能据此认定所有 C/S 站网格均为同一材料。\cite{att-hardware}

物理上，穿过孔隙而未碰到网丝的粒子不会因这次材料穿越而损失能量；$T=1/10$ 表示名义粒子透过率约 10\%，不表示粒子能量降至十分之一。degrader 则让粒子穿过材料来降低能量。网丝边缘散射仍可能改变束晕及接受度，故名义 ATT 倍率不等同于已测得的末端透过率，也不单独证明极化保持。

\subsection{AVF--RRC 段的站位与 ATT 倍率出处}
2014 年年报在 C22、S31a、S64 的诊断腔明确列有 beam attenuation mesh。C22 位于 AVF 与 RRC 厅之间墙的上游；S31a 在 S3 rebuncher 上游；S64 在 S6 rebuncher 之后、RRC 注入之前。原图见图\ref{fig:att-location}。\cite{att-chambers}

\subsection{网格组合、Duty 与实际标定}
按上述倍率，取两块 $1/2$、一块 $1/10$、一块 $1/5$ 和一块 $1/100$ 为计算示例，五块网格的理想透过率乘积为
\[
T_{\mathrm{example,nom}}=\frac12\frac12\frac1{10}\frac15\frac1{100}
=\frac1{20000}=5\times10^{-5}.
\]
这是倍率组合示例，不指定各块的安装站位。
全照射清单逐项相乘则为 $8.33\times10^{-11}$；这个形式乘积不代表可用范围，原页没有解释它与标示 $10^{-9}$ 下限的差异。

用下式做强度收支时，必须指定输入测量面和 ATT 状态：
\[
\langle\dot N_{\rm out}\rangle
=\dot N_{\rm in,on}\,D\,T_{\rm ATT,eff}\,\eta_{\rm rest},
\qquad T_{\rm ATT,nom}=\prod_{i\,\mathrm{IN}}T_i.
\]
$D$ 为所定义时间窗口的束流开启比例，$T_{\rm ATT,eff}$ 为实际有效透过率，$\eta_{\rm rest}$ 包含其余传输、俘获和引出效率。网格乘积近似要求照明与下游接受度允许这种因子化。若输入已是时间平均值，不再乘一次 $D$；若已是某组 ATT 插入后的出口电流，也不再重复乘同组倍率。E5A 的 Duty $=100\%$ 不表示回旋加速器没有 RF 束团，探测器 pile-up 仍取决于束团结构。

实际标定要看末端监测量。E5A 第 8 页以 2017 年 Kr 束的 Att scan 将低率塑闪计数与高率电离室电流在比例区连接，给出 $R_{\rm PL}[\mathrm{cps}]=7.505\times10^{12}I_{\rm IC1}[\mathrm A]$，并用 $19.63\,\mathrm{cm^2}$ 孔面积换算平均 flux（见图\ref{fig:e5a-att}）。\cite{e5a} 该系数依赖 Kr、气体及探测器设置，不能移用于氘束。IC1 电流来自气体电离，不能按 Faraday cup 的 $I/(qe)$ 直接换成入射粒子率。

\section{从 SRC 强度估算 ATT 需求}
\label{sec:att-budget}
假设某次运行在\textbf{上述示例五块 ATT 全拔出}时，SRC 出口实测参考强度为 $30\,\mathrm{pnA}$，并假定插网后其余传输条件不变，则
\[
\dot N_{\rm SRC,0}=1.872\times10^{11}/\mathrm s,
\qquad
\dot N_{\rm SRC,ATT}\simeq\dot N_{\rm SRC,0}/20000
=9.36\times10^6/\mathrm s.
\]
要从这个参考值降至 $10^7$/s，需要 $T_{\rm eff}\leq5.34\times10^{-5}$（即衰减倍数至少 $1.87\times10^4$）。若参考值改为 $120\,\mathrm{pnA}$，同一乘积得到 $3.74\times10^7$/s，仍高于该目标。

以上是条件计算。官方 $30\,\mathrm{pnA}$ 预期值没有同时给出 ATT 的组合与状态，故不能直接宣称“五块全插就能满足本次实验限值”。同样，源端 $<100\,\mu\mathrm A$ 与 SRC 的 $30\,\mathrm{pnA}$ 来自不同条件，二者相除不能得到实测的 PIS--SRC 传输效率。

对 after-SRC 极化仪，最直接的输入是该位置在指定源模式、ATT 组合和时间窗口下的实测束流。上游 ATT 降低进入 RRC/SRC 的粒子率，也会影响 after-SRC 可用率；若想在 after-SRC 保持较高强度、下游再限流，需依据下文的束线接受度与联锁条件确定方案。

\section{束线位置与功能}

BigRIPS 第一段从生产靶 F0 到 F2，第二段从 F3 到 F7；F2 与 F3 之间是约 8.8 m 的匹配段。分段来自官方配置说明，长度来自技术参数表。\cite{bigrips-config,bigrips-technical} 束流路径示意为
\[
\mathrm{SRC}\;\longrightarrow\;\mathrm{T\ course}\;\longrightarrow\;F0\;\longrightarrow\;D1/F1\;\longrightarrow\;F2\;\longrightarrow\;dF2\;\longrightarrow\;F3.
\]
F0 后的 D1 间隙内设置高功率 beam dump，用于截停未反应的一次重离子束；第一段的 F1 是动量色散焦点，F2 是消色差焦点，F3 是第二段的起点。\cite{bigrips-config} 原文见图\ref{fig:config-source}；dF2 的位置见图\ref{fig:slit-source}。

\section{F3 的强度限制}

RIKEN BigRIPS 官方束流说明要求在申请书中填写 ``Total Beam Rates @ F3''，并指出由于辐射法规，该处总束流率不能超过 $10^7$/s。官方建议在 LISE++ 中在 F3 后插入 Faraday Cup 2 检查该数值。\cite{bigrips-intensity} 原文见图\ref{fig:f3-source}。这里按总束流率计入目标核素及杂质，不能只用目标核素产额比较限值。

该网页面向 RI 束产额估算和实验申请。2015 年 BIS 论文也直接讨论一次束送至 BigRIPS 下游实验装置的模式，并给出 $10^7$ pps 限值。\cite{bis2015} 因此该数量级有一次束运行依据；本次偏极氘束的具体区域、模式和设定阈值仍应由束线组确认。对于适用该规定的运行模式，本文据此推论：下游触发降采样只减少记录事件，不会减少经过 F3 的粒子数，因此不能替代 F3 总率控制。

\section{一次束与 RI 束模式的区别}

对于 F0 产生 RI 束的标准模式，F0、D1 beam dump、F1 degrader/slit 和 F2 collimator 共同完成一次束截停及 RI 束选择。\cite{bigrips-config,bigrips-focal} 对于将一次束送入 BigRIPS 的模式，RIKEN 2025 年 BIS 年报说明：系统根据 ATT 插入状态判断衰减是否足够；衰减不足时，会在 SRC 出口插入 Faraday cup。\cite{bis} 对应原文见图\ref{fig:bis-source}。2015 年论文给出更具体的既有逻辑：以经常测量的源强和低能 ATT 状态评估最大可能束流；衰减满足条件才允许拔出 SRC 出口 FC\_G01，运行中状态改变而衰减不足时，以 beam chopper 和 FC\_G01 截束。\cite{bis2015} 这是一套上界估计与保护逻辑，并非 SRC 出口的连续无损电流实测。2025 年报还描述了该功能的改造，故不把 2015 年实现直接当作当前完整时序。

\begin{samepage}
基于上述联锁说明，本文的工程判断是：``SRC 后保持高流强，在 F2 或 dF2 再降到允许值'' 不能仅由狭缝几何推断为可运行方案。必须确认该模式下的联锁阈值、束损位置、F2/dF2 狭缝的热负荷和屏蔽条件。
\end{samepage}

\section{对 after-SRC 偏振仪的建议}

以下为本文的实验规划建议，不是 RIKEN 已批准的运行方案。偏振氘束实验建议把需求拆成两个独立量：
\begin{enumerate}
  \item after-SRC 极化计处的一次束强度和允许的探测器计数率；
  \item F3 处（若束流继续进入 BigRIPS 下游）的总束流率，包括杂质。
\end{enumerate}
优先向束线组询问是否存在专门的局部衰减器或可接受的 F2/dF2 准直方案，而不要把普通 F2 狭缝直接当作高功率 beam attenuator。若需要保持偏振，任何材料衰减器还应单独评估多重散射、能损、核反应和可能的自旋系统误差。
