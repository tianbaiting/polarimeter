## Project scope

The current baseline contains two in-vacuum instruments:

- `CompactInVacuum-afterSRC`
- `CompactInVacuum-preSAMURAI`

Both are generated by `compactInVacuum/src/civ/`. The compatibility name `CompactOne` remains in
targets and commands. The models under `external_version/` use the older
`external_version/infrontofSamuraiMag/src/ifsm/` engine and are legacy external-detector references,
not current baseline instruments.

## Mechanical scope

The CompactInVacuum baseline uses four in-vacuum three-channel sector holders. The current afterSRC
profile screens a 440 x 440 x 420 mm chamber with an all-metal ICF305 top maintenance opening.
Internal supports remain on permanent chamber structure; the removable closure carries no detector,
support, datum, ground, or cable-restraint load. Only the first 12 mm release motion is currently
validated; full reorientation and lift remain unresolved.

H+V+V plates, external detector packages, historical ICF114/ICF70 contracts, and VF/VG interfaces
belong only to the selected legacy external route unless separately promoted by approved evidence.

## Analysis code

ROOT-based reconstruction and inference live under `code/` and must run in `anaroot-env`:

```bash
micromamba run -n anaroot-env cmake -S code -B code/build -DDPOLAR_BUILD_TESTS=ON
micromamba run -n anaroot-env cmake --build code/build
micromamba run -n anaroot-env ctest --test-dir code/build --output-on-failure
```

Use `skills/dpolar-count-inference/SKILL.md` for count-to-polarization inference and
`skills/infront-freecad-engineering/SKILL.md` for stateful CAD or coupled CAD-analysis work.

Generated `code/build/`, `code/output/`, CAD artifacts, caches, and runtime state are not source
files and must not be committed.
